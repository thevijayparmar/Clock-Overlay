Clock Overlay — Demo

This page loads clock-overlay.config.js then clock-overlay.js exactly like a real site would. Open this file directly in a browser (double-click it) — no server or build step needed.

Try it now

By default the overlay auto-opens after 3 minutes of no scrolling — that's the real "idle" trigger a visitor would experience. To see it immediately instead of waiting, use the public API:

What to check

Once it's open: try the ☀️ 🌑 🌤️ 🌦️ color themes, the 🕰️ clock-style picker (digital / big digital / analog + digital / analog / big analog), the 🌏 sky-effects ring menu, fullscreen (⛶), and the Developer panel button inside the settings (⚙️) panel — it shows live geolocation/weather/AQI/3D-renderer diagnostics and a manual time-override slider so you can preview any hour of the day instantly.

Configuration

Every option — idle timeout, default theme, starting sky effects, and the sun/moon texture paths — lives in clock-overlay.config.js, not in the engine file. Open it in a text editor to change any of it.
